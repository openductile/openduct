# Governance

OpenDuct is created and maintained by Ductile AI, Inc.

## Maintainers

Until the project has regular outside contributors, the maintainers are Ductile AI. Maintainers:

- review and merge pull requests - only maintainers merge, and every change to `main` goes through a reviewed pull
  request with passing checks;
- decide the roadmap, releases and what is in or out of scope;
- handle security reports (see [SECURITY.md](SECURITY.md)) and enforce the [Code of Conduct](CODE_OF_CONDUCT.md);
- own the project's name, trademarks and repositories.

Every Contribution is made under the [Contributor License Agreement](CLA.md).

## Growing the project

We want OpenDuct to be a community project. As regular contributors join, we intend to invite them to become
maintainers, write down how maintainers are added and how decisions are made, and update this document. Changes to
this document are made by pull request, like any other change.

## Decisions

Technical decisions are made in the open - in issues and pull requests - and recorded there. Where a decision
changes how OpenDuct behaves on the wire, how it stores data or what it guarantees, it is written up in `docs/` first.
