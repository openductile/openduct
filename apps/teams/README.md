# Microsoft Teams

Messages posted to a [Microsoft Teams](https://www.microsoft.com/microsoft-teams) channel.

## Signing in

Add an incoming webhook to the channel (Workflows, or the channel's connectors) and copy its address into a Teams webhook credential.

## Actions

- **Post a message** (`send`).

## Tested

Recorded exchanges (`tests/`), and OpenDuct's own workflow and alert tests.
