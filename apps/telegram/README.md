# Telegram

Messages sent through a [Telegram](https://telegram.org) bot.

## Signing in

Talk to **@BotFather** in Telegram, `/newbot`, and copy the bot's token into a Telegram credential. Add the bot to the chat (or channel) it writes to.

## Actions

- **Send a message** (`send`): to a chat's id or `@channelname`, optionally marked up as MarkdownV2 or HTML.

## Tested

Recorded exchanges (`tests/`), and OpenDuct's own workflow and alert tests.
