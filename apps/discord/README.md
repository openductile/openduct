# Discord

Messages posted to a [Discord](https://discord.com) channel.

## Signing in

In the channel's settings, **Integrations → Webhooks → New Webhook**; copy its address into a Discord webhook credential.

## Actions

- **Post a message** (`send`): optionally under a name of your choice.

## Tested

Recorded exchanges (`tests/`), and OpenDuct's own workflow and alert tests.
